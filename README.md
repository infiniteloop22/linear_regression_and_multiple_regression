# linear_regression_and_multiple_regression

This class exercise uses scipy for calculating the p-value and statsmodels is used for performing multiple linear regression.

- Functions:
  - Loading the data.
  - Visualizing scatterplots with matplotlib.
  - Calculating the slope and intercept of the regression equation.
  - Performing the prediction with user's input.
  - Helper functions for calculating the f-statistic and r-squared value.
